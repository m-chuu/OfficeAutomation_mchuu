Project Overview

Gain Measurement of Broadband Amplifier

This project uses RsInstrument, an open-source Python module, to enable remote-control communication with Rohde & Schwarz SCPI-based Test and Measurement Instruments.

Software Package

RsInstrument is a Python module developed for remote control of Rohde & Schwarz test and measurement devices. It is distributed under the open-source MIT License.

Function

The script performs a daily automated measurement of the gain (in dB) of a broadband amplifier using a Rohde & Schwarz ZNB Vector Network Analyzer. This is typically done following amplifier repair and calibration. The script also:

  • Imports a previously saved gain file.
  • Configures instrument parameters.
  • Initiates and logs the gain measurement process.
